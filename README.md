# Подсчёт автомобилей на видео с помощью YOLOv8

## Описание проекта

В данном проекте реализована программа для детекции, трекинга и подсчёта автомобилей на видео.

Для решения задачи используется модель YOLOv8 из библиотеки Ultralytics.  
Программа находит автомобили на каждом кадре, присваивает им уникальные ID с помощью трекинга BoT-SORT и считает автомобили, которые пересекают заданную линию.

## Этапы работы

### 0 этап. Выбор видео

Для тестирования используется видео `video.mp4`, на котором видны движущиеся автомобили.

### Этап 1. Детекция и трекинг машин

Для детекции используется YOLOv8.  
Используется класс `car` из датасета COCO. Его номер — `2`.

Также включён трекинг BoT-SORT, который позволяет сохранять ID автомобиля между кадрами.

### Этап 2. Линия подсчёта

В программе задаются две точки линии:

```python
LINE_POINT_1 = (200, 350)
LINE_POINT_2 = (1000, 350)
Линия отображается на видео.

### Этап 3. Логика подсчёта

Для каждого автомобиля вычисляется центр bounding box.

Если центр автомобиля был с одной стороны линии, а потом оказался с другой стороны, программа считает, что автомобиль пересёк линию.

Один и тот же автомобиль учитывается только один раз. Для этого используется множество counted_ids.

### Этап 4. Визуализация

На видео отображаются:

bounding boxes автомобилей;
ID каждого автомобиля;
центр автомобиля;
линия подсчёта;
общее количество пересечений.

Если автомобиль уже был посчитан, его рамка становится красной.

### Этап 5. Тестирование

После запуска программа создаёт итоговое видео result.mp4, где можно увидеть работу детекции, трекинга и подсчёта.
